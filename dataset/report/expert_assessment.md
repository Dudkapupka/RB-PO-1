# Экспертная оценка безопасности

## Область сканирования

Сканирование проводилось в отношении собственной виртуальной машины Ubuntu в UTM с IP-адресом 192.168.64.2.

Для сетевого сканирования использовалось ограничение скорости запросов. Сторонние IP-адреса GitHub, полученные через GitHub Meta API, непосредственно не сканировались.

## Критические находки

Критических уязвимостей не обнаружено.

## Средние находки

Уязвимостей среднего уровня не обнаружено.

## Низкие находки

Уязвимостей низкого уровня не обнаружено.

## Результаты инструментов

1. **Nmap** — открытые порты и доступные сетевые сервисы на исследуемом узле не обнаружены.
2. **Masscan** — открытые порты в исследованном диапазоне не обнаружены.
3. **Nikto** — веб-сервер на портах 80 и 443 недоступен, поэтому веб-уязвимости не обнаружены.
4. **Nmap NSE** — порт 443 закрыт, анализ HTTP security headers выполнить невозможно.
5. **Nuclei** — уязвимости не обнаружены; HTTPS-порт цели недоступен.
6. **Horusec** — локальный статический анализ проекта завершён успешно, уязвимости не обнаружены.

## Рекомендации

1. Закрывать все неиспользуемые порты.
2. Регулярно обновлять операционную систему и программные зависимости.
3. Не хранить пароли, токены и API-ключи в Git-репозитории.
4. Периодически выполнять статический анализ исходного кода.
5. При развёртывании веб-сервиса повторить анализ с помощью Nmap, Nikto и Nuclei.
6. Настроить автоматический анализ безопасности проекта в CI/CD.
7. Включить двухфакторную аутентификацию GitHub.
8. Регулярно проверять зависимости проекта на известные уязвимости.

## Правовое соответствие

Сканирование выполнялось только в отношении собственного ресурса — виртуальной машины Ubuntu. Сторонняя инфраструктура GitHub не подвергалась активному сканированию.
