# Security Scan Dataset

Датасет содержит результаты учебного анализа безопасности собственной виртуальной машины Ubuntu.

Целевой адрес: 192.168.64.2

Использованные инструменты:
- Nmap
- Masscan
- Nikto
- Nuclei
- Horusec

## Структура

- data/scan_findings.csv — единый датасет находок
- data/raw/ — исходные результаты инструментов
- meta/scan_findings.meta — метаданные
- report/expert_assessment.md — экспертная оценка
- report/sources.md — использованные источники

В ходе проведённых проверок уязвимости обнаружены не были.
